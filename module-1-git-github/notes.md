## Key vocabulary (in your own words)

- repository: your project folder and edit history
- commit:  a saved file of your project
- branch: a separate workspace where you can test without doing any changes in main branch
- push / pull: push will upload the file to the github and pull download the uploaded file
- pull request: a request to merge your own branch to the main
- merge conflict: it is when Git pauses because two people edited the exact same line, it requires a manual fix
